# 工具：list_dir（列目录）

| 状态 | 最后更新 | 关联代码 | 代码基线 |
|---|---|---|---|
| Stable | 2026-10-16 | `tools/list_dir.py` | `515d604` |

> 所属：[工具系统总览](README.md) ｜ 写作规范见 [docs/README](../../README.md)

## 1. 职责

列出工作区内某个目录的内容（文件和子目录）。
模型想知道"项目里有什么"时用的第一个工具——也是最简单的一个
（写新工具时适合照抄它的三段结构）。

## 2. 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `path` | string | 否 | 相对工作区的目录路径（如 `static`）；不传 = 列工作区根目录 |

## 3. 行为与输出

- 遍历目录并**按名字排序**（输出稳定，方便模型对照）；
- 跳过隐藏项（`.` 开头，如 `.git`、`.workbuddy`）和 `__pycache__`——
  免得模型在垃圾堆里迷路（这个做法学自 Pi 的 `ls` 工具）；
- 子目录名带 `/` 后缀（程序员熟悉的标注方式）；
- 输出格式：

  ```
  目录 static 的内容：
  index.html
  marked.umd.js
  purify.js
  ```

- 空目录返回 `（这个目录是空的）`。

## 4. 错误路径

| 情况 | 返回 |
|---|---|
| 目录不存在 | `错误：目录不存在：xxx` |
| 路径是文件不是目录 | `错误：这不是一个目录：xxx` |
| 路径越界（`../` 等） | `safe_path` 抛 ValueError → 由 `toolbox.call` 兜底转成 `错误：工具执行失败：路径越界：…` |

## 5. 实现要点与坑

- **不递归**：只看一层（模型需要递归就自己多调几次，或派子代理去翻）；
- 隐藏项过滤是"硬编码"的（`.` 开头的全都跳）——如果将来想列 `.env`
  这类需要显式支持；
- 排序是 Python 默认字符串序（大小写敏感、不区分"目录优先"）。
